# Scheduled sweep task

Use the `job_sweep` tool once. Review only the returned canonical records. Report new qualified leads, duplicates, rejected counts, and failures. Use built-in plan or goal tracking when multiple discovery adapters are enabled. Delegate independent source review through Harness subagents only when the active profile provides them and the configured activity limit permits it.

Do not submit applications, send messages, publish content, or write to a remote tracker. For any candidate action, call `job_application_handoff` and stop for exact-job human approval.
